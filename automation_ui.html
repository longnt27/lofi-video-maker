Kết nối extension trong hai profile Chrome — làm một lần

Extension thao tác trong tab riêng ở nền. Quyền Debugger gửi phím trực tiếp đến tab của bot để nhập ô Excel; không chiếm bàn phím/chuột hệ thống. Quyền Downloads nhận file vừa tạo. Cài đúng bản theo profile:


main: Excel · Flow video · Flow Music


gpt: ChatGPT tạo ảnh hai lần


Trên trang extension: Developer mode → Load unpacked → chọn đúng thư mục trên. Nạp lần đầu tự ghép nối. Khi đổi tài khoản: Dừng → chọn tên Chrome mới ở dưới → mở Chrome đó → nạp cùng extension → mở popup extension và bấm “Dùng profile này”. Profile cũ không nhận việc nữa.
