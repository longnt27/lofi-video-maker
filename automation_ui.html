Kết nối extension trong hai profile Chrome — làm một lần

Extension thao tác trong tab riêng ở nền để tạo và tải ảnh, video, nhạc. File Excel trên máy được Studio đọc và cập nhật trực tiếp. Cài đúng bản theo profile:


main: Flow video · Flow Music


gpt: ChatGPT tạo ảnh


Trên trang extension: Developer mode → Load unpacked → chọn đúng thư mục trên. Nạp lần đầu tự ghép nối. Khi đổi tài khoản: Dừng → chọn tên Chrome mới ở dưới → mở Chrome đó → nạp cùng extension → mở popup extension và bấm “Dùng profile này”. Profile cũ không nhận việc nữa.


Cấu hình quy trìnhStudio đọc kịch bản và tick hoàn thành trong file này. Đóng file trong Excel khi automation lưu kết quả.
